# Dominion OS™ public demo artifacts

This public repository is intentionally limited to public-safe demonstration artifacts and sanitized proof metadata.

It is **not** the Dominion OS source repository or a production control plane. Private source, credentials, signing material, customer data, payment data, private APIs, operational keys, internal automation, infrastructure definitions, and production controls do not belong here.

The public demo fails closed: no provider runtime is claimed live without a separate current machine-produced certification receipt.
